# 图片放置说明

四角装饰图与封面图都从这个目录读取。图片缺失时页面会自动显示带项目名的虚线占位框，不会裂图。

## 文件命名（必须一致）

| 文件 | 位置 | 用途 |
|------|------|------|
| `deco-tl.jpg` | 首页左上角 | 遗川（建议竖图 3:4） |
| `deco-tr.jpg` | 首页右上角 | 银色巨人（建议竖图 3:4） |
| `deco-bl.jpg` | 首页左下角 | 白役（建议竖图 3:4） |
| `deco-br.jpg` | 首页右下角 + 终电后项目页封面 | 终电后（建议竖图 3:4） |

## 推荐风格

超写实风格，厚涂和晕染的水粉技法，明显的颜料涂抹感、肌理感与颗粒感，搭配对比色让色彩绚丽（暗底页面建议图片亮度适中，避免过暗）。

## 替换方法

直接把同名文件覆盖进 images 文件夹即可，无需改代码。支持 jpg / png / webp，只要扩展名与引用一致。
