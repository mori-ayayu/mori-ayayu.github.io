# CRT SCREEN —— 一台纯粹的老式显像管

打开页面：暗室里的屏幕先黑着，随后自动通电，经历「亮线展开 → 几何校准网格 → 自检文本逐字输出 → 待机」的完整冷启动。点击屏幕任意处可重新冷启动（第一次点击会同时开启开机音效：电源咔哒、消磁哼声、高压啵、行频啸叫，纯 WebAudio 合成，无外部音频文件）。

零构建、零依赖，纯静态文件，直接扔到任意静态托管（GitHub Pages 等）即可用。

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架与接线 |
| `style.css` | 屏幕之外的部分：暗室、外壳、玻璃圆角、电源 LED |
| `crt.js` | WebGL 引擎：曲面畸变 / RGB 色差 / 行间暗缝扫描线 / 暗角 / 噪点雪花 / 荧光粉曲线 / 玻璃反光 / 交流闪烁 |
| `stage.js` | 荧光屏上的内容：冷启动状态机、终端打字机、待机、字符雨过渡、主菜单、学習 |
| `sound.js` | 开机音效与菜单交互音合成 |
| `world-data.js` | 世界资料数据（蜩坂町町势要览的 TreeView 结构化版） |
| `study-data.js` | 学習数据：假名表（清音/濁音/片仮名/拗音）与 N1 精选词汇 |
| `world-template.md` | 世界资料 TreeView 模板与填写规则 |
| `assets/Background.jpg` | 菜单背景图原图（高清，http 环境下优先使用） |
| `assets/bg-data.js` | 菜单背景图内嵌兜底数据（base64，本地双击 file:// 打开时使用） |

架构：内容先画在一块低分辨率 2D 画布上（相当于荧光屏原生画面：高固定 480，宽随窗口比例变化），每帧上传为纹理，再由 WebGL 片元着色器做「隔着球面玻璃看荧光屏」的全部处理。屏幕本身始终填满整个浏览器窗口，比例跟随窗口。以后想加任何内容，都只需要往内容层画，CRT 效果自动套用。

## 预览

直接双击 `index.html` 即可（无任何外部资源）。也可以起本地服务：

```
python -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

## 修改内容

### 1. 冷启动自检文本

`stage.js` 顶部 `BOOT_SCRIPT` 数组，一行一项：

```js
{ c: 't', rate: 26, hold: 240, t: '高電圧《こうでんあつ》 .............. 正常《せいじょう》' },
```

- `c`：颜色角色 `t` 正文 / `d` 暗 / `b` 高亮
- `t`：行文本，支持振假名语法：`漢字《かんじ》` 会在汉字上方显示小的注音（沿用于全站文字）
- `rate`：每个打字单元的基础间隔毫秒（带注音的词整词输出，普通文本逐字输出，均带随机抖动）
- `hold`：本行打完后停顿毫秒

时间轴常量在同文件下方：`T_GRID_START`（网格出现）、`T_TEXT_START`（开始打字）、`T_HOLD_MS`、`T_FADE_MS`；行高 `LH`（已预留注音空间）。

**打字方式**：打字基准线固定在屏幕中心——文字从画面中心开始出现，当前行停在中心不动，换行时已完成的行被向上顶一格（终端式向上生长）；屏上方能完整容纳的行数由 `MAX_ROWS` 控制（默认 9），超出后最旧的行从顶部滚出。

### 2. 待机、字符雨与主菜单

待机画面点击后播放一段字符雨过渡（ASCII / 英文字母 / 平假名 / 片假名，覆盖全屏），然后进入主菜单。冷启动动画播放中点击屏幕会弹出「是否跳过」确认框：确认后经字符雨直接进待机，取消则继续。菜单界面：右侧为背景图展示区（四边羽化渐变融入画面；宽窗口下内容右界以图片视觉右缘为界）；下方为菜单列表（写真帖 / 文書 / 学習 / 箱庭 / 再起動）。底部左侧为返回按钮 `[待機へ戻る]`（**不再有点空白返回；所有页面点空白均无动作**）。鼠标悬停的菜单项会被 『』 框选，点击执行。窗口较窄时菜单自动切换为紧凑纵向布局。

**用户信息与待定面板**：宽窗口（≥940px）为**三栏布局**——左用户面板 / 中内容 / 右『未定』面板，默认展开且互不重叠；**屏幕左上角与右上角各有一枚对称的 `[≡]` / `[×]` 按钮**，分别独立控制左右面板的收合（中间内容位置固定，不随面板收合移动）。窄窗口下两侧面板均变为**浮动面板**（默认折叠，左右两角按钮分别控制）。所有浮层绘制在页面内容之上（菜单/树不会被面板文字穿透叠加）。仅可点按钮收起，点面板外不会收起。**「設定」为面板内的树节点**：点击展开、再次点击折叠，展开后设置项直接显示在下方。设置树全区展开时面板底边仍与底部按钮留有间隙，不压字。

### 3. 设置界面

用户面板（宽窗口为左侧面板；窄窗口为浮动面板）内有一个**「設定」树节点**：点击展开 / 再次点击折叠，设置项直接显示在下方。**树节点箭头为 `›` 字符**：收起时朝右、展开时旋转 90° 朝下，切换带短促的翻转过渡（约 150ms 平滑旋转，中途连点从当前角度接续不跳变）。**每项也是树式条目**：点击展开、再次点击收起（同时只展开一项）——数值项（明るさ / 音量 / 曲面 / 走査線 / 雑音 / 残光）展开后出现 `[－] 滑条 [＋]`；蛍光体展开后为 `●緑 / ○琥珀 / ○白` 横排子选项，点击直接选择。设置实时生效并自动保存到 localStorage（刷新后保留）；按钮悬停高亮，点击有短促提示音。

新增设置项：往 `SETTINGS_ITEMS` 数组加一项即可（`type: 'range'` 数值项填 min/max/step 与 get/set，`type: 'enum'` 枚举项填 values/labels 与 get/set，签名均为 `(stage)`），界面自动渲染按钮与滑条。

**背景图机制（双保险）**：`assets/Background.jpg` 是高清原图，页面加载时会先在临时画布上做"污染探测"，干净才使用（http/https 环境正常走这条）。若探测失败（如 file:// 直接双击打开，浏览器会把本地图片视为跨源，直接使用会让 WebGL 报安全错误导致黑屏），则自动回退到 `assets/bg-data.js` 里的内嵌小图（base64，永远干净）。
- 上传部署后换图：直接替换 `assets/Background.jpg` 即可
- 本地双击也要显示新图：需要重新生成 `assets/bg-data.js`（把新图缩到 1280 宽转 base64）
- 羽化浓度与透明度在 `_makeFeather`（边缘渐隐带比例）和 `_drawMenuBg`（整体 alpha）里调
- 图片素材左缘与菜单 『>』 列对齐（窄窗口下与左栏对齐），构图在区域内左对齐、垂直居中

增加菜单项：往 `MENU_ITEMS` 加一项即可（id 唯一；`label` 日语主文本 + `ruby` 注音 + `en` 英文下位装饰），占位项点击会提示 `未接続`；要给某项接真实内容，在 `Stage.tap` 的 `menu` 分支按 `id` 处理，或直接把该项 `phase` 切到新的界面绘制函数（照 `_drawMenu` 的模式加一个 `_drawAlbum` 之类的渲染方法并在 `render` 的 switch 里登记）。

**界面文字**：全部使用日语（汉字优先，振假名注音），英文仅作为下位装饰（如菜单右侧小号英文）。所有带注音的文本都走 `parseRuby()` 解析 + `_drawUnits()` 渲染；自己写新界面时直接 `this._drawUnits(ctx, parseRuby('漢字《かんじ》'), x, y, color)` 即可，注音会自动以主字一半字号居中在汉字上方。

### 4. 箱庭页（树视图）

菜单点「箱庭」进入：右侧显示箱庭资料树（TreeView），内容右界同样以背景图视觉右缘为界。层级用缩进表达（无连线符号），树节点箭头为 `›` 字符（收起朝右 / 展开旋转 90° 朝下，带翻转过渡），点击节点展开 / 折叠；鼠标悬停的节点会被 『』框选（与菜单一致）；支持鼠标滚轮与手机手指滑动滚动，内容超一屏时右侧显示滚动条，底部 `[戻る]` 返回菜单。

数据在 **`world-data.js`**（当前为《蜩坂町町势要览・1999》的完整结构化版：十三大章，含山川地理、交通、街道、设施、四十八世带的居民名簿、人名典据等）；节点结构、折行规则与逐层填写方法见同目录 `world-template.md`。`lines` 里的长文本会按句读自动分段折行（标点不会落在行首），不会出现大段连续文字；滚动浏览。

**时钟位置**：所有页面的时钟统一显示在右下角（与待机页一致），顶部只保留页面标题。

### 5. 学習（仮名練習・語彙記憶）

菜单点「学習」进入，内含两个项目：

**仮名練習**：进入后是阶段选择，五个阶段依次递进——
1. 一階 清音（46 字）：平假名 → 罗马字
2. 二階 濁音・半濁音（25 字）
3. 三階 片仮名（46 字）：片假名 → 罗马字
4. 四階 拗音（33 字）
5. 五階 総合（150 字）：前四种混合

每阶为四选一：随机出现一个假名（64px 大字居中），下方四个罗马字选项；答对即出下一题，答错显示正确答案后同样进入下一题（反馈停留 1.1 秒）。同音假名（じ/ぢ、ず/づ）不会在选项中重复出现。右上角记录本局「正解 n / m」，各阶累计成绩存于 localStorage（`kx15.study`），阶段页右侧显示累计正解数。

**語彙記憶**：同样的四选一模式，随机出现 N1 词汇（显示词 + 振假名读音），四个选项为中文释义。题库在 `study-data.js` 的 `STUDY_WORDS`（当前 175 词精选），新增词条直接往数组里加 `{ w:'书写', r:'读音', m:'释义' }` 即可。

答题页布局：标题行（左上）、阶段/范围与本局统计（右上）、题干（中央）、四个编号选项（竖排居中）、底部 `[戻る]`（假名返回阶段页、词汇返回学习首页）。选项悬停高亮，答对后正确项高亮、其余变暗。

数据文件：`study-data.js`（假名表 + 词汇库），由 index.html 在 stage.js 之前加载；假名表为 `{ name, ruby, items: [[假名, 罗马字], ...] }`，第五阶「総合」在文件末尾自动合并生成。

### 6. 磷光体颜色

键盘 `1` 绿磷 / `2` 琥珀 / `3` 白磷（调试用，正式页可删）。调色板在 `stage.js` 的 `CRT.PHOSPHORS`：

```js
green: { bg:'#020602', line:'#1d4f28', text:'#8ff28f', dim:'#12401f', bright:'#e2ffe2' }
```

颜色按「荧光屏上看到的亮度」设计：`bg` 黑位、`text` 正文、`bright` 高亮、`dim` 低亮度弱元素。

### 7. 渲染参数

浏览器控制台直接改，立即生效：

```js
__crt.config.curve = -0.05;  // 曲面强度基准值。实际强度随窗口比例三次方衰减：
                             // 4:3（及更窄窗口）保持基准 -0.05；16:9 全屏 ≈ -0.015；更宽继续减弱
__crt.config.overscan = 0.94;// 过扫描裁边（0.94 已接近全幅）
__crt.config.scanline = 0.9; // 行间暗缝
__crt.config.noise = 0.05;   // 噪点雪花
__crt.config.glare = 0.65;   // 玻璃反光
__crt.config.glow = 0.1;     // 荧光晕散
__crt.config.vignette = 0.5; // 暗角
__crt.config.flicker = 0.01; // 交流闪烁
__crt.config.gamma = 1.0;    // 荧光粉曲线
__crt.config.chroma = 0;     // RGB 色差（将来放彩色内容时开到 0.01~0.03）
```

## 上传部署

整个目录直接上传。GitHub Pages 示例：

```
crt-screen/  ← 作为仓库根目录，或放进 docs/
```

**手机端适配**：横向窗口（桌面 / 手机横屏）内容高固定 480、宽随比例；**竖向窗口（手机竖屏）内容宽固定 480、高随比例、画面垂直居中**，上下留出屏幕玻璃的暗区，自检文本 / 菜单 / 设置等界面排版在竖屏下不会被挤坏。触屏下按下与滑动会同步悬停高亮（『』框选、按钮高亮可见），触屏设备的渲染倍率自动降为 1.5 保帧率。

注意**内容安全区**：屏幕有 overscan 裁切与曲面压缩，内容画布四周约 3% 会被裁掉、再向外有曲面收边，文字请保持距边 ≥40px（stage.js 里已按此设置边距）。横向窗口下内容画布高度固定 480、宽度随窗口比例变化，画布变窄时文本会自动按像素宽度断行。
